🌟 Mentor Website :

A HTML & CSS website designed to showcase courses, trainers, events, and pricing. Built with HTML5, CSS3, and Font Awesome icons for a modern, professional look.

🚀 Features :

Smooth scrolling links.

Home Section: Hero banner with headline & call-to-action button.

About Section: Introduces your team or services.

Courses Section: Shows stats like students, courses, events, and trainers.

Trainers Section: Highlights key trainers or team members.

Events Section: Engaging icons with brief descriptions.

Pricing/Courses Section: Popular courses with images, prices, and details.

Dropdown Section: Trainer cards with social media links.

Footer Section: Contact info, useful links, services, newsletter subscription, copyright.

🛠 Tech Stack :

HTML5

CSS3
 
Font Awesome Icons .
